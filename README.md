# 22기 영업관리시스템

GitHub Pages 공개 버전입니다. 프로젝트 등록 항목은 프로젝트명, 고객사, 확인 요청 제품입니다.

원본 엑셀의 고객사, 담당자, 인력 명단, 단가와 영업 내역은 공개 배포본에서 제외했습니다.
입력한 데이터는 현재 브라우저의 localStorage에만 저장되며 사용자 간 공유되지 않습니다.
회원가입, 로그인, 관리자 승인 비밀번호 초기화는 아직 구현되지 않았습니다.

## 배포

GitHub Settings → Pages에서 Deploy from a branch, main, /(root)를 선택합니다.
index.html, app.js, styles.css를 수정하여 main에 반영하면 자동 배포됩니다.
